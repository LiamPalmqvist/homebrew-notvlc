# Homebrew tap for NotVLC

[NotVLC](https://github.com/LiamPalmqvist/NotVLC) is a media player built on VLC's engine with a
redesigned interface.

```bash
brew install --cask liampalmqvist/notvlc/notvlc
```

It needs VLC 3 (`brew install --cask vlc`, or VLC from videolan.org) and an Apple silicon Mac.

The cask is updated by NotVLC's release workflow; its source is
[`packaging/homebrew/notvlc.rb`](https://github.com/LiamPalmqvist/NotVLC/blob/main/packaging/homebrew/notvlc.rb)
in the NotVLC repository.
